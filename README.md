# online-food-ordering-system
A simple Online Food Ordering System built using HTML, CSS, and JavaScript with cart and checkout features.


# Online Food Ordering System

## Features
- Menu with Veg / Non-Veg items
- Add to Cart
- Search functionality
- Checkout page
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Just open index.html in a browser.
